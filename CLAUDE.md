## Commands

```bash
npm run dev          # Start Vite dev server
npm run build        # Type-check then build for production
npm run lint         # Run ESLint
npm run test         # Run tests in watch mode
npm run test:run     # Run tests once (CI)
npm run test:coverage  # Run tests with coverage report
```

Run a single test file:
```bash
npx vitest run src/path/to/file.test.tsx
```

## Environment

Copy `.env.example` to `.env`. The only required variable is:
```
VITE_API_URL=http://localhost:8000/api/v1
```
This points to a Laravel backend. Default login: `admin@example.com` / `password`.

## Architecture

### Routing

File-based routing via TanStack Router. **Never edit `src/routeTree.gen.ts` directly** — it is auto-generated by the Vite plugin on `npm run dev` or `npm run build` when route files change.

Route structure:
- `src/routes/__root.tsx` — root providers (QueryClient, ThemeProvider, AuthProvider, TooltipProvider)
- `src/routes/_authenticated.tsx` — authenticated layout (sidebar + header); redirects to `/login` if no `access_token` in localStorage
- `src/routes/_authenticated/**` — all protected pages
- `src/routes/login.tsx` — public login page

### API & Auth

`src/api/client.ts` — Axios instance that attaches Bearer token from `localStorage.access_token`. On 401, it attempts a token refresh at `/auth/refresh`; on failure it clears storage and redirects to `/login`.

Each resource has its own API module in `src/api/` (e.g. `form-templates.ts`, `form-submissions.ts`). All server state is managed via TanStack Query.

`src/lib/auth.tsx` — `AuthProvider` + `useAuth` hook. The `isAdmin` flag is `user.role.name === 'admin'`.

### Form Builder

The form builder is the most complex feature. It uses **TanStack DB** (client-side reactive store) with **localStorage** persistence, rather than server-fetched state.

Data flow:
1. `src/db-collections/form-builder.collections.ts` — defines the `formBuilderCollection` (TanStack DB collection stored in `localStorage["form-builder"]`) with Valibot schemas for all element types.
2. `src/services/form-builder.service.ts` — imperative CRUD functions (`appendElement`, `dropElement`, `editElement`, `reorder`, `loadFormTemplate`, `resetFormBuilder`, etc.) that write to `formBuilderCollection`.
3. `src/hooks/use-form-builder-state.ts` — `useLiveQuery` subscriber that reactively reads `formElements`, `formName`, and `settings` from the collection.
4. On **save**: `src/lib/schema-generators/generate-rjsf-schemas.ts` converts the internal `FormElement[]` representation into a JSON Schema + UI Schema pair, which is persisted to the backend via `formTemplatesApi.updateFormTemplate`.
5. On **load**: `src/lib/schema-generators/reverse-rjsf-schemas.ts` reverses the stored JSON/UI Schema back into `FormElement[]`.

Form elements support a `FormArray` type (repeatable grouped fields). `FormArray.arrayField` is the template; `FormArray.entries` holds instantiated copies with namespaced field names (`arrayName[i].fieldName`).

### Form Submission (RJSF)

`src/routes/_authenticated/forms/$templateId.tsx` and the submissions routes render forms using `@rjsf/shadcn` (shadcn-themed RJSF). The stored `json_schema` and `ui_schema` from the backend are passed directly to `<Form>`. Submissions are versioned on the backend.

### UI Components

`src/components/ui/` — shadcn/ui components. Add new ones with `npx shadcn add <component>`.

`src/components/ui/tanstack-form.tsx` — wraps TanStack Form (`@tanstack/react-form`) with shadcn field primitives (`FormItem`, `FormLabel`, `FormControl`, `FormMessage`).

Path alias `@` maps to `src/`.

### Testing

Tests use Vitest + Testing Library with jsdom. Global setup is in `src/test/setup.ts` (mocks `authApi`, `matchMedia`, `ResizeObserver`, `localStorage`, `scrollIntoView`).

`src/test/test-utils.tsx` exports two helpers:
- `renderWithProviders(ui, { user?, token? })` — wraps in QueryClient + ThemeProvider + AuthProvider
- `renderWithRouter({ route?, user?, token? })` — full router render for route-level tests

Import from `@/test/test-utils` instead of `@testing-library/react` to get the wrapped versions. `authApi.me` is auto-mocked in setup; pass a `user` object to `renderWithProviders`/`renderWithRouter` to simulate an authenticated session.
